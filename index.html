ducknng browser wasm demo

This static site loads the ducknng DuckDB extension as a duckdb-wasm side module and runs the browser smoke page. The current public demo proves extension load, codec/registry calls, and the inproc:// AIO RPC manifest path when the pthread runtime has cross-origin isolation.

It does not claim browser support for ipc://, raw tcp://, native tls+tcp://, HTTP, or WebSocket transports.
