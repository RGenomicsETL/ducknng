ducknng in the browser.

This static site loads the ducknng DuckDB extension as a duckdb-wasm side module and runs the browser smoke page in your own tab — no server, no install.

Open the smoke page Browser support contract

What it proves Extension load, codec and registry calls, and the inproc:// AIO RPC manifest path when the pthread runtime has cross-origin isolation. What it does not claim No browser support for ipc://, raw tcp://, or native tls+tcp://. Capabilities are negotiated, never simulated. Supported carriers HTTP and HTTPS, plus framed RPC over ws:// and wss://, using the browser trust store.
